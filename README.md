# vkr-project
# НИР: Разработка цифрового решения для ESG-ориентированного развития городской зелёной инфраструктуры (на примере города Краснодара)

## Описание
Проект посвящён созданию цифрового решения для поддержки ESG-ориентированного развития городской зелёной инфраструктуры.  
Цель — разработка инструментов для анализа, мониторинга и планирования зелёных зон города Краснодара с учётом экологических, социальных и управленческих критериев ESG.
