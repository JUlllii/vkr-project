# vkr-project
# НИР: Разработка цифрового решения для ESG-ориентированного развития городской зелёной инфраструктуры (на примере города Краснодара)

## Описание
Проект посвящён созданию цифрового решения для поддержки ESG-ориентированного развития городской зелёной инфраструктуры.  
Цель — разработка инструментов для анализа, мониторинга и планирования зелёных зон города Краснодара с учётом экологических, социальных и управленческих критериев ESG.

## Цель работы
Разработать цифровое решение, которое позволит:
- визуализировать существующую зелёную инфраструктуру;
- оценивать эффективность зелёных зон с точки зрения ESG;
- формировать рекомендации по улучшению городской экологии и социального воздействия.

## Задачи
- Сбор данных о зелёной инфраструктуре Краснодара (площади, виды растений, экологические показатели)  
- Разработка базы данных для хранения и обработки информации  
- Создание веб-интерфейса для визуализации и анализа данных  
- Разработка инструментов ESG-оценки зелёной инфраструктуры  
- Подготовка отчетов и рекомендаций на основе анализа данных
